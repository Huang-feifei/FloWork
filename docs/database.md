# 数据库工作台

主应用的数据库模块（不是 `flowork-desktop.vetd/` 中的示例数据），与 Pi 会话和内核更新互相独立。由 Electron 桌面主进程承载后端，界面通过 IPC 访问。

## 入口与连接

- 点击活动栏的 **数据库**。首次欢迎页、应用菜单「视图」及命令面板也能打开，不需要先导入项目或配置模型。
- 新建连接可选 **SQLite / PostgreSQL / MySQL**，可先测试再保存；支持编辑、移除和多个连接。
- SQLite 打开后端机器上的已有绝对路径文件，不自动创建数据库，不支持通过 SSH 访问远程文件。提供原生文件选择，也可填写本机绝对路径。
- PostgreSQL / MySQL 填写主机、端口、数据库、用户名及密码。更新连接时省略密码会保留原密码，界面提供单独的清除选项。
- 可开启 TLS，使用驱动的证书验证和系统信任配置，**不提供忽略证书验证或静默降级**。当前没有自定义 CA/客户端证书编辑器。
- 可复用「远程主机」中保存的 SSH 连接建立隧道；数据库主机地址和端口是 **从 SSH 主机看过去** 的地址。复用系统 SSH 配置、私钥/agent/密码认证及主机密钥校验。首次连接沿用 `accept-new`；已有主机密钥变化时阻止连接并进入现有指纹核对流程。
- 隧道只监听 `127.0.0.1`，每次操作结束、取消、超时或关闭后清理，不开放公网端口。不需要远端安装 Node 或数据库客户端。

## 表数据与 SQL

**数据** 标签支持：枚举表/视图、查看字段类型/主键/可空属性、WHERE 表达式筛选、按合法列升降序、每页 25/50/100/250 行、翻页与刷新。没有主键时数据库不保证默认行顺序；数据发生变化时基于 OFFSET 的分页也可能出现重复或遗漏。

**查询** 标签使用带语法高亮的 SQL 编辑器，支持格式化、`Ctrl/Cmd+Enter` 运行、保存/加载收藏、查看/加载/清空当前连接的查询历史。

- 每次只执行一条 SQL；SQL 最大 100,000 字符。
- 默认执行上限 30 秒，支持取消；建 SSH 隧道另有最多 15 秒等待。
- 查询结果最多 5,000 行，结果数据累计最多 12 MiB；超过行数时标记为截断。大文本单元格截断至 65,536 字符，二进制只展示摘要，大整数以字符串保留精度。
- CSV 导出/复制只包含 **当前页或本次查询已返回的结果**，不是整库或全表备份；字符串单元格做公式注入防护。NULL 输出为空字段。
- 切换到会话/设置等主视图会保留当前数据库工作区及进行中的操作；应用关闭/回到欢迎页卸载工作区时会取消执行。取消或连接中断不等于数据库一定未写入。

## 只读与写入边界

默认新连接为只读。SQL 文本检查仅用于保守地判断是否需要写入确认，**不是数据库权限沙箱**：

- SQLite 读操作以只读文件连接打开并启用 `query_only`；网络数据库读操作使用数据库强制的只读事务。即使连接配置允许写入，被分类为读的查询仍使用只读事务。
- INSERT / UPDATE / DELETE 等 DML 和允许的 DDL 需要关闭连接的只读选项，并对每次 SQL 明确确认。
- 写入确认是一次性凭证，绑定当前客户端、完整连接配置和原始 SQL，120 秒有效；连接配置或 SQL 改变后必须重新确认。
- 不接受多语句脚本、用户事务控制、PRAGMA、ATTACH/DETACH、COPY、CALL、SET、可执行注释等语句；MySQL 禁用多语句和 LOCAL INFILE。
- 普通写操作在独立事务中提交。SQLite / PostgreSQL 的可回滚写操作遇到错误或返回过多行时回滚；**MySQL DDL 可能隐式提交，不能承诺取消、超时或错误可以撤销已执行的变更**。
- 只读事务也不等于对数据库所有扩展/UDF 或外部系统的沙箱。生产环境建议使用数据库自身的最小权限只读账号，避免授予超级用户、文件访问或危险函数权限。需要长期事务、存储过程脚本、导入/备份等高级管理操作时使用专用数据库工具。
- 查询在独立 Node 子进程中执行，避免 SQLite 长查询卡住 Electron 主进程。凭据经 stdin 传入，不放到命令行。取消/超时会结束客户端执行进程并清理隧道，但远端服务器可能需要时间感知断连；尤其写操作必须先核对结果，**不要自动重试**。

## 本地存储

连接、查询历史、收藏保存在 `getFloworkDataDir()/databases.json`（默认 `~/.flowork/databases.json`，可用 `FLOWORK_DATA_DIR` 隔离）。文件串行原子写入，POSIX 权限为 0600；配置损坏时明确报错，不静默覆盖。

- 桌面版系统加密可用时，数据库密码通过现有 `safeStorage` 接口加密落盘；编辑旧明文记录时迁移为密文。Renderer 只能看到 `hasPassword`，拿不到保存的密码。
- 系统加密不可用时，密码仍可能以明文存储。无法解密的桌面密码不会被静默清除，需重新填写。Windows 文件访问还依赖当前用户目录的 ACL，0600 不是跨用户密码保险箱。
- 最多保留全局 500 条历史，每个连接界面读取最近 100 条；最多 500 条收藏。SQL 和错误内容可能包含敏感信息，历史和收藏并未加密。
- 当前 SQL 草稿及最近连接选择保存在 Renderer localStorage。移除连接会移除对应的连接配置、历史、收藏和当前浏览器中的草稿，**不会删除真实数据库文件或数据**。

## 开发验证

```bash
npm test -- database                 # 类型检查及离线 SQLite/安全回归
node scripts/test-database.mjs       # 不依赖预构建的离线回归

# Git Bash / POSIX shell：自动创建并清理隔离容器，不接触生产数据库
FLOWORK_TEST_DATABASES=1 node scripts/test-database.mjs

# 自动起 Electron 子进程，验证其实际 Node 与 ASAR 内生产驱动加载
FLOWORK_TEST_DATABASE_ASAR=1 FLOWORK_TEST_DATABASES=1 \
  node scripts/test-database.mjs
```

网络回归需要 Docker，使用 `postgres:17-alpine` 和 `mysql:8.4`，临时随机端口仅发布到回环地址，没有宿主机数据卷。首次可能拉取镜像。

可选 `FLOWORK_TEST_DATABASE_SSH_IMAGE=<测试镜像>` 增加 SSH 隧道和主机密钥变化回归：镜像需已安装 OpenSSH server、`chpasswd`、`ssh-keygen`，默认以前台 root sshd 作为 PID 1。脚本只在新建的临时容器内配置测试认证，known_hosts 写入临时文件，不修改真实 SSH 信任记录。

主要实现：`src/core/database.ts`（注册表、凭据、确认、隧道、子进程）、`src/core/database-runner.ts`（驱动与事务）、`src/shared/database*.ts`（类型、SQL/CSV）、`src/renderer/src/components/database/`（界面）。
